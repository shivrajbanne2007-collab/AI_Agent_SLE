# DSA Question Recommender Agent

## Project Overview

The DSA Question Recommender Agent is a Python-based recommendation
agent that suggests Data Structures and Algorithms (DSA) questions
according to the user's selected topic, difficulty level, and number
of questions.

This project was developed as part of the Introduction to AI
Self-Learning Activity to demonstrate responsible use of AI coding
assistants.

## Objective

The objectives of this project are:

- To understand the use of AI coding assistants in software development.
- To build a simple recommendation-based AI agent.
- To practice Python programming.
- To use Git and GitHub for version control.
- To maintain an AI Contribution Log.
- To understand responsible and transparent use of AI-generated code.

## Features

- Select a DSA topic.
- Select a difficulty level.
- Enter the required number of questions.
- Randomly select questions from the available database.
- Validate invalid topics and difficulty levels.
- Prevent requesting more questions than available.
- Display question titles and descriptions.

## DSA Topics

The current version contains questions from:

1. Array
2. Searching
3. Sorting
4. Stack
5. Queue

Each topic contains questions classified as:

- Easy
- Medium
- Hard

## AI Tool Used

GitHub Copilot was used as an AI coding assistant during development.

AI was used to assist with:

- Creating the initial DSA question database.
- Developing the recommendation logic.
- Implementing input validation.
- Implementing random question selection.

AI-generated code was reviewed, tested, and modified where required.

All significant AI contributions are documented in
`Contribution_Log.md`.
